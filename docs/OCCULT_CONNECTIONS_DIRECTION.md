# 写真の繋がりから架空の事件を読む

2026-10-23。ユーザーの追加フィードバックを受けた制作方針。新しい完成問題・公開済みコンテンツの仕様ではない。

## 求める体験

４枚を選ぶと「物の分類が当たった」で終わらず、写っていた物の用途や、誰に何が起きているかの見え方が変わる。プレイヤーが写真の関係に先に気づき、答え合わせで自分の読みを確かめられることを重視する。

現在の「歯が並ぶ道具」などは関係としては成立するが、この恐怖の体験には届かない。写真に糸や蝋を加えても、その正解自体の弱さは変わらない。次の内容は、関係と真相を先に設計してから写真を制作する。

## 維持するもの

- 12枚の画像、４枚で１組、全３組を仕分ける。
- 初期の推理材料は画像。文字の資料収集や儀礼名の暗記を必須にしない。
- 普通の人が現代のスマホで撮ったような写真。日常の物や生活空間に、用途の分からない痕跡を残す。
- 選択・照合・短い開示を中心とした簡潔な操作。外部AI APIによる自由回答の判定は追加しない。
- 閲覧・拡大の回数を推理の障害にせず、何をどう見るかはプレイヤーに委ねる。

## 先に設計する内容

１組ごとに次を揃える。

1. **繋がりを一文で表す。** 「同じ素材」「口を塞いだ物」だけで終わらず、それらを合わせることで用途・対象・出来事が判明する関係を検討する。
2. **４枚それぞれの観察可能な根拠を書く。** 解説だけに出てくる村の掟や固有名詞を根拠に数えない。
3. **何を見誤りやすいかを書く。** 身体・弔い・身代わりなどに見える複数の読みを検討し、怖い関係を後付けしただけになっていないか確認する。
4. **12枚全体で別の分け方を検討する。** 編集上の所属表の唯一解と、実際に写真から成立する別解を区別する。表を列挙しただけで人間の解釈全般の唯一性を保証しない。
5. **正解時の視覚的な説明を決める。** 写真の該当箇所を結び、短い一文で判明した事実を示す。長文の背景説明を読まなければ意味が分からない開示にしない。

## 恐怖の方向を示す一例

「弔いの準備」と見えていた写真が、組み合わせることで「弔われる本人は、まだ生きている」と分かる。

これは制作方向を示す例であり、採用済みの物語や完成した４枚の組ではない。生存・対象人物・時間関係を画像内にどう示すかが成立しないなら、怖い説明が書けても問題としては採用しない。最後にだけ『実は生きていた』と告げる構成では足りない。

## トーンと事実の境界

身体にまつわる因習、呪物、儀式、不穏な生活の痕跡を中心にする。少しグロテスクな質感も検討するが、血や損壊の量を増やすこと自体を繋がりの面白さの代わりにしない。

事件の人物・土地・具体的な加害行為はフィクションとして設計する。実在の民俗を着想元に使うなら、確認できた記録と作中の脚色を区別して紹介する。共有された文章の間引き・身体損壊等の具体例には典拠がなく、そのまま実在の慣行として公開しない。

## 次の内容を採用する判断基準

- 正解の一文に、発見したい事実や意味の変化があるか。
- その発見を、回答前の写真から説明できるか。
- ４枚全部が繋がりの根拠として働いているか。
- 同じ印・糸の色・傷などを４つ探すだけになっていないか。
- ある程度は複数の読みが浮かび、それでも全体の仕分けを考える余地があるか。
- 解説で架空の掟を聞かされて初めて正解が成立していないか。
- 作中の出来事と実在の伝承の説明が混同されていないか。

現行の公開デモは挙動の土台として保持する。今回の方針整理だけで、新しい問題や画像を公開済みとは扱わない。
