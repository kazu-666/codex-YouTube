# 異聞調査録（仮称）・３話の考察デモ

2026-10-23 日本時間。ユーザーが合意した「考察→背景を知る→地域を明かす→地図に記録」を試す最小版。正式名と本番の運営ルールは未決定。

## 今回の遊び方

URLから第１話を直接開く。登録・ログイン・最初のモード選択は不要。短い出来事と独自の再現イラストを見て、２枚の資料を開く。好評だった封筒の開封演出を共通部品として使い、約１秒で手がかり本文を表示する。いつでも閉じて考察へ戻れる。動きを減らす設定では直ちに読むことができる。

「調査報告書を開く」を押すと、２カ所の空欄と候補語が出る。空欄を選び、候補語をタップして埋める。ドラッグや自由入力は不要。一つ埋めると次の空欄へ移る。記入後も空欄を押して変更でき、資料も読み直せる。「この報告書で確定する」で一度だけ回答する。空欄ごと50点・各話100点・計300点。資料を読んでも減点しない。これは知識や考察の深さをAIで評価する採点ではなく、記録に基づく２つの関係が一致するかの判定。

答え合わせでは完成した報告書、一致した部分、どの手がかりが根拠になるか、詳しい話を表示する。次に「この話の土地を知る」を押すと、初めて地域・場所・出典が開き、調査地図にピンが残る。不正解・部分正解・回答見送りでも全解説と土地を公開する。場所を当てる回答や距離による得点は使わない。

調査地図には開いた地域だけを載せ、未調査の場所や正解座標を先に見せない。ピン・記録カードから読み返せる。最後に３話の成績を画像共有・PNG保存・投稿文コピーできる。投稿用の画像と文には題名・場所・正解を載せない。投稿先と送信は端末の共有画面で利用者が選ぶ。

## 画像・地図

問題中の画像はこのデモ用に作ったSVGの再現イラスト。写真・古い絵巻・現場資料の転載ではない。図の細部に実在の記録以上の意味を与えず、文章で推理に使う情報を確定させる。３枚とも地域名や正解を含まない不透明なファイル名。

地域公開後に希望する人だけが、既存のEsri World Imageryの周辺航空写真を開ける。最初の問題や答え合わせ画面では取得しない。撮影日は未確認。画像の帰属を表示し、正式公開・商用利用の条件確認は継続する。現地を地上から撮った写真の用意は残る。

地図の海岸線は既存のNatural Earth / world-atlasデータを使用し、ライセンスへのリンクを保持。地域の概略ピンで、精密な施設の位置を回答させたり訪問を誘導したりしない。ローカルのSVGで描くため外部地図タイル・WebGL・別の地図エンジンの読み込みがない。

## 実装・保存

`server/casebook.js` のAPIで資料開封・報告書の確定・地域公開を処理。初期レスポンスには正解、本文未開封の資料、地域、出典、将来の問題の内容を含めない。報告書の候補は開いた後、正解は回答後、場所と出典は別の地域公開操作の後に返す。航空写真も地域を開いたセッションだけに配信する。

回答は送信IDで重複を検出し、異なる回答の再送を防ぐ。二つの空欄の部分点はサーバーで確定する。通信が回答確定後に切れた場合は保存済み状態を取り直して復帰する。地域の重複記録でも点やピンは増やさない。

匿名Cookieと `.data/sessions.json` に `deduction-demo-v1` として保存。日付で消えない固定３話の調査録で、毎日の新問運用はまだない。旧地図版の進行とは別。単一プロセスの試作保存で、Render無料環境の再起動・再デプロイによって失われる場合がある。会員向け永続保存・本番のデータベース・課金・公開ランキングは後続。

新デモの入口は `/?mode=casebook` またはパラメーターなしのルート。旧地図版は `?round=first` / `?round=second` のURLで保持し、必要な時だけ旧コードを読む。新画面で約1MBの旧地図コードや地図workerを先読みしない。以前の参考記事・比較表は資料として保持する。

無料モードの結果画面に広告領域を配置。実際の配信コードは未接続。既存の有料デモ状態では枠を出さないが、新しい３話はすべて無料で遊べる。課金状態の切替・料金表示は新画面には設けていない。
