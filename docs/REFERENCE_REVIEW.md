# GeoSports 公開情報の調査記録

確認日：2026-10-22。参照サイトと公開配信ファイルは更新され得る。ユーザー提供の画面写真も照合した。これは公開情報の観察であり、非公開の設計やサーバー内部を確認したものではない。

## 確認できたルールと操作

- [How GeoSports works](https://geosports.app/how-it-works) は、毎日共通の5問、米東部時間の午前0時更新、地球儀のドラッグ回転とピンチ拡大、タップ1回で回答確定、途中で更新しても進行保存と説明している。これはデフォルトの操作説明。2026-10-22に再取得した下記の公開クライアントには `confirmToLock` と `Confirm location before locking in` があり、仮置き後に確定する設定もある。「送信ボタンは一切ない」とは言い切れない。
- 1問の素点は最大100点。後半の重みづけは `100 + 100 + 200 + 300 + 300 = 1,000` 点。距離と素点の関係は同ページの説明に限って確認した。採点式そのものは本作へ流用しない。
- ユーザー提供の GeoSports/GeoFooty 画面写真では、暗色のUIの下に衛星画像の地球儀、拡大時は地域の衛星画像、上に地名・国コードが見える。静止画だけから操作方法は判断していない。

## 公開された画面配信から分かる構成

- [ページの HTTP レスポンス](https://geosports.app/how-it-works) には `x-powered-by: Next.js` と Vercel の応答ヘッダーがあった。ヘッダーだけではデータベースや採点サーバー内部の構成は分からない。利用サービスについては、下記の追加確認で公式プライバシーポリシーの記載が見つかった。
- [公開地図スタイル JSON](https://geosports.app/map-style.json) に衛星写真用の Esri World Imagery ラスタータイル、OpenFreeMap のベクトル地図、国境線・国名のレイヤー、出典表示が定義されていた。
- 公開ブラウザ用スクリプトに `projection: {type: "globe"}`、地図のピンチ・ドラッグ設定、地図クリック処理があった。配信CSSには MapLibre GL のクラス名があった。ブラウザ用コードから分かるのはクライアント表示の仕組みまでで、サービス全体のソースコードや運営手順は公開されていない。
- GeoSports の公開地図コンポーネントには `maxZoom: 9` が見える。本作は厳島神社など個別施設を指定するため最大19まで拡大する。見た目と文章も独自にする。

## 回答後の表示の追加確認

同日に `/play` と、そのHTMLから直接参照される公開JavaScriptを再取得した。[対象の配信ファイル](https://geosports.app/_next/static/immutable/chunks/2zronavmezudi.js) では、回答を採点後、地図の表示範囲を動かし、回答地点と正解を結ぶ大円弧をアニメーション表示する処理、回答・線の表示・正解公開に伴う効果音、得点表示の更新、距離に応じた短いコメントが確認できた。回答後のカードには得点、倍率、距離、正解の場所名と `answer.story` が表示される。「距離だけを表示するゲーム」という説明は不正確。

また、問題データの `question.image` が存在する場合に、問題ヘッダーの下へ画像と任意のクレジットを表示するコンポーネントがある。これは回答後専用の現地写真表示とは異なり、全問で正解地点の写真が必ず出ることを確認したものではない。今回の確認は公開コードの読解で、実機で各演出や画像を再生確認したものではない。

本作の現状は、固定の2地点ピンと経路線・即時の表示範囲調整、距離と得点、短い解説と出典であり、現地写真や段階的な正解公開の演出は未実装。SNS用の共有得点画像と、各問回答後に見る現地写真は別の機能として扱う。回答後の体験は、実在地点の写真（利用条件と出典を確認）、場所名、信仰・伝承との具体的なつながり、地図上の位置関係を中心に改善する必要がある。

## 本作への判断

運営費の調査で [GeoSports公式プライバシーポリシー](https://geosports.app/privacy)（更新日2026-08-19と記載）も取得した。Vercel（ホスティング）、Neon（DB）、Upstash（キャッシュ）、Resend（メール）、Stripe（決済）、PostHog（解析）、Playwire（広告）などの利用が明記されている。これは事業者の公開説明であり、契約プランや作者の実際の請求額を確認したものではない。料金確認の進捗と本作の暫定予算は [運営費調査](OPERATING_COSTS.md) を参照。

本作は MapLibre GL JS を使い、地球儀の背景に衛星写真、その上に詳細な地名・道路などを表示する。画像が取得できない場合もベクトル地図で回答できるようにする。ドラッグ回転、ピンチ拡大、タップによる1回の回答確定を採用し、タッチ操作の誤選択をブラウザで検証する。回答後の解説・出典、無料/有料ヒント、広告の位置、日英表示、採点式は本作独自の仕様を維持する。

現在の即確定の操作は本作のデモ実装。仮置き後の確認も「各問1回の回答」と両立するため、今のSNS・YouTubeの視聴者を対象とする試遊で比較する。[本格開発前の整理案](CONCEPT_REVIEW.md) を参照。

Esri 画像の実際の配信、対象施設の写真解像度、商用利用条件は本番公開前に対象サービスの利用条件と実機で確認する。今回のクラウドから `server.arcgisonline.com` への接続はプロキシに拒否されたため、ブラウザ操作テストでは衛星タイルを代替画像に置き換える。OpenFreeMap の公開スタイルへの接続は確認できた。
