# 受信記録 001「赤い包みのある集落」

2026-10-23 日本時間。仮称は「異聞調査録」。実在の民俗を着想元に、人物・集落・出来事は創作する一話の試作。雨穴氏や既存ゲームの人物・文章・画面を使用しない。

## 今回の修正

ユーザーは前のデモについて「画像がAI画像に見える」「もっとstrangeなUI」「iPhoneで素人が撮影したような画像」と指摘し、UIは「スマホに届いた写真やメッセージを調べる、不穏な画面」を選んだ。続けて、画像を探すためのタップは不要、画像と文字で情報を与えるだけでよく、GeoSportsのようなシンプルさを保つよう指定した。

そこで見取り図、探索マーカー、開封、比較専用画面、独自の画像拡大操作、回答前の確認ダイアログを外した。新しい写真風生成画像と短文３件を最初から並べ、下の一問に回答する。暗い受信記録の画面で、出し惜しみ・自動タイピング・突然の音やグリッチを足さない。普通のページスクロールで全部読める。

## 遊ぶ流れ

入口は `/?mode=fieldwork` またはパラメーターなしのルート。登録不要。

1. 祠に置かれた供え物の画像と「川沿いの小さな祠で、これを見つけました」。
2. 作りかけの画像と「近くの家にも、作りかけがありました。中には綿を詰めるそうです」。
3. 赤ん坊を抱く人物と同じ供え物の画像。「この子がお腹いっぱいになりますように」という証言。
4. 「この供え物に託された願いは？」の三択を選び、一回回答する。
5. 正誤と100点満点の得点、短い解説が出る。希望する人が「詳しい背景・実在の着想元を読む」を開く。

正解は「母乳が出ること」で100点。不正解・見送りは0点でも、全解説を読める。正解名の暗記や自由記述のAI採点は使わない。前版にあった「乳房の形」の回答欄は削除し、画像の形は推理材料と解説に使う。回答用の言葉は当初から表示するが、正解・詳しい話・実在の着想元は回答後にサーバーから返す。

結果のコピー・PNG保存には点数だけを載せ、答え・地域・画像の被写体を載せない。確認して一話をやり直せる。毎日の新問、連続する長編、会員機能、課金、広告配信は未実装。題材そのものはまだ試作で、写真とUIを直したことを面白さの検証とはしない。

## 創作と実在の着想元

既存３話の制作時に2026-10-23本文確認済み。[出典台帳](../research/deduction-demo-source-review.json) の `kappa` に本文ハッシュと確認日がある。今回新たに別の風習を追加したわけではない。

着想元は、乳神の祠、乳の出を願う女性、赤い布で乳房の形を作る供え物。効能や怪異の実在を証明するものではない。人物・集落・証言・画像の具体的な木板や縫製、民家、祠の外観は創作。実在する住民や家を描いた記録写真として扱わない。画面冒頭に「創作の受信記録・生成画像」、末尾に写真の生成と創作の注記を出す。

## 保存・検証

`server/fieldwork.js` が匿名セッションの `fieldwork[riverside-message-v2]` に回答を保存。前の探索版の回答は別のキーに残る。新しい画面は inspect / options を呼ばず、状態取得と回答・やり直しだけを使う。採点はサーバー。送信IDによる再送の重複防止と、確定後に応答が消失した場合の状態取り直しを維持する。

保存は既存の試作用ローカルJSONで、Render無料環境の再デプロイ等により消える場合がある。旧３話と旧地図版の保存とは別。

API検証：初期の正解非公開、回答項目の検証、Origin拒否、候補公開操作なしでの回答、同時再送と改変拒否、再起動後の復元、不正解・見送りでの全解説、旧デモと別セッションの分離、やり直し。

ブラウザ検証：390pxタッチ設定、320px・動きを減らす設定、1280px。実際のローカル生成画像を使用。探索操作なしで全写真・短文・三択が出ること、外部地図を読まないこと、横はみ出しなし、回答の確定応答だけ失われる場合、リロード、背景と出典、ネタバレなしの結果コピー・PNG保存、やり直しと見送り、画像失敗時の再試行。クリップボード書き込みはテスト用に代替。実機のiPhoneでの見え方、好み、面白さは未検証。
