# 画像から調べる一話「赤い包みのある集落」

2026-10-23 日本時間。正式名は未定、制作上の仮称は「異聞調査録」。ユーザーが選んだ「実在の民俗を着想元にし、集落・人物・事件は創作する」方針の最小試作。雨穴氏や既存作品の文章、人物、村、展開、画面は使用しない。一般的な資料照合と考察の形式を使い、独自の一話を作る。

## 遊ぶ流れ

`/?mode=fieldwork` またはパラメーターなしのルートから直接一話を開く。登録不要。集落の見取り図には番号付きの３地点があり、同じ３地点を一覧からも開ける。調査対象の細かいクリック探しはさせない。

1. 川辺の祠：同じ形の赤い供え物が複数ある画像を観察する。
2. 仕立て部屋：布と綿、縫いかけの形を見る。
3. 民家の縁側：同じ物を持つ、赤ん坊を抱いた人物と短い証言を見る。

順番は自由。初回は約0.8秒の開封として画像を上から表示し、調査メモへ記録する。画像の一部を見られる時間に制限を設けない。開閉・再表示は自由で、初回演出をリロードのたびに繰り返さない。動きを減らす端末設定では即時表示する。

画像は100〜300%のボタン拡大と二本指のピンチに対応。拡大後は閲覧枠内を指でスクロールし、余白に出た被写体を見られる。本文やボタンのサイズをズームに合わせて拡縮しない。「全体を拡大」から見取り図も同じ閲覧枠で確認可能。画像を並べる画面から各原寸表示へ戻れる。

「考察をまとめる」を押した後に回答候補を出す。二つの項目をタップで選び、最終確認して一度答える。画像３枚は回答中も開ける。調査へ戻っても候補の下書きは残る。画像を何度開いても減点しない。「答えを見る」は０点として全解説へ進む。やり直しにはゲーム内の確認を置き、この一話の記録だけを消す。

## 編集用の正解（ネタバレ）

- 形：乳房、40点。
- 願い：母乳が出ること、60点。
- 二つで100点。自由記述をAIが評価する方式ではない。
- 丸い二つの形だけでは用途は決まらない。中身を渡す袋でなく形をまねた物であること、作りかけ、子のために願う人物を合わせて考える。ただし民俗の未知の名前を当てさせる問題にはしない。
- これは難易度を調整する前の短い体験例。正解が唯一論理的に導ける実地試験、面白さ・再訪率・市場性の検証は未実施。

答え合わせでは二項目の正誤と点数、同じ集落上で三地点がつながる線、三つの画像とそれぞれの根拠、創作の物語を表示する。別に開く「着想元になった、実在の風習」には現実の地域と出典を載せる。架空の集落を実在の地図に位置登録しない。

## 実在の着想元と創作の境界

遠野市観光協会「カッパ淵」：<https://tonojikan.jp/tourism/kappabuchi-pool/>。

2026-10-23に既存３話の制作で本文確認済み。確認記録と本文ハッシュは [出典台帳](../research/deduction-demo-source-review.json) の `kappa`。今回改めて未確認の別の風習を出典へ追加していない。

参照した範囲は、乳神を祀る祠、乳の出を願う女性、赤い布で乳房の形を作って納めること。効能・怪異が科学的に実在する、現在全住民が実行している、などの意味ではない。

ゲームの集落、調査員、母親、家と橋の位置、証言、木板に縫い付ける具体的な製法はすべて創作。現地の写真・民具の復元図を装わない。生成画像には「生成イラスト」、冒頭と末尾には創作の注記を表示する。現実の住民や実在する旧家の秘密を特定する遊びにしない。

## 画像

この一話用に image_gen で生成した四等分の一枚。上左が集落、上右が祠、下左が作りかけ、下右が人物。画像生成後に目視で、丸い二つの形・片方が平らな作りかけ・人物が同じ物を持つことを確認。調査地点は背景に対応する位置へ配置した。時代を特定する記録写真ではない。

元PNGは実行環境の `/workspace/generated_images/exec-0ec7c0dd-876c-4c3c-b3e6-d8b86c31073a.png` に残す。サイト用には図柄や色を加工せずWebPへ形式変換し、[village-sheet.webp](../web/public/fieldwork/village-sheet.webp) を収録。1536×1024、約412KB。一枚をCSSで四つの表示領域に分け、場面切り替えや拡大ごとに画像を再生成・追加取得しない。すべてローカル静的素材。画像ファイルに正解文や現実の地名を埋め込まない。

## 実装と保存

`server/fieldwork.js` が匿名セッションの `fieldwork[riverside-offering-v1]` を保存する。GET状態には見取り図・観察可能な画像説明だけを含め、候補は考察を開いた後、正解・詳しい物語・実在の着想元は回答後に返す。画像自体は観察対象なので公開静的ファイルとする。

POST inspect / options / answer / reset を使用。正解と点数はサーバーで確定。UUIDの送信IDと回答内容を照合し、応答消失後の再送で二重に加点しない。同じ送信IDで別の回答へ変えることは拒否。通信が切れたときは状態を再取得し、確定済みの結果を回収する。元の３話・地図デモとは保存欄を分ける。

匿名のローカルJSON保存という既存の試作基盤を使うため、Render無料環境の再デプロイ等で失われる場合がある。会員向けの永続保存、課金、ランキング、実広告、毎日の新問、複数話の連続物語は今回追加していない。結果画像・コピー文は点数と正誤マークのみで、場所・正解・画像の被写体を含めない。
