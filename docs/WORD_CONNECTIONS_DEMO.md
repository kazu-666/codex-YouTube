# 十二の言葉：４語×３組のデモ

2026-10-23。ユーザーが指定した12単語のConnections型パズルと、その後に了承した『古事記』の作例を実装。`kojiki-words-v1`。入口は `/` または `?mode=connections`。固定１問であり、日替わりではない。

## 盤面と正解

12語：櫛、大豆、桃、入れ歯、麦、黒御鬘、鋸、蚕、葡萄、歯車、稲、筍。初期はランダムな４列×３行。同じゲームでは初期配置を維持し、プレイヤーが並べ替えられる。読み仮名を表示。初期のタイトルは「十二の言葉」とし、歯・黄泉・身体という答えのカテゴリを先に明かさない。

| 難易度 | カテゴリ | ４語 |
| --- | --- | --- |
| 初級・黄 | 歯が並んでいる道具 | 櫛・鋸・歯車・入れ歯 |
| 中級・緑 | 黄泉からの逃走を助けたもの | 黒御鬘・葡萄・筍・桃 |
| 最難関・紫 | 殺された神の身体から生まれたもの | 蚕・稲・麦・大豆 |

黒御鬘は『古事記』の頭の飾りを指す。中級の対応は、黒御鬘→葡萄、櫛の歯→筍、桃→追手を退ける。最難関は、大宜都比売神の頭→蚕、目→稲、陰部→麦、尻→大豆。

神話の起源譚として説明し、現実に行われた殺人儀礼の記録として表示しない。典拠は『古事記』上巻、黄泉国訪問／大宜都比売神の段。現代語の要約は本作で作成。國學院の古事記学センターと日本語Wikisourceへの今回の取得は管理プロキシのCONNECT403で、リンク先本文を読んだとは表示しない。出典欄に書名・参照箇所・オンライン未照合を明記する。

## 罠と唯一性の範囲

櫛は初級だけでなく中級の定義にも属する。中級の候補５語から４語を選ぶとき、櫛を含めると初級を４語で満たせなくなる。12語の完全な分割には櫛を初級へ戻す必要がある。

`content/word-connections.json` の編集用所属表で、カテゴリ別の候補集合を定義。各集合から４語を列挙し、３組の和集合が12語で重複しない分割が一つであることをテストする。意味の所属表自体は初期APIへ返さない。

この検証は指定した３カテゴリの定義の下での唯一性。プレイヤーが別のカテゴリを作る可能性を、列挙やAIで完全に否定したとはしない。難易度の妥当性・神話の既知度・別解の受け止め方は試遊で確認する。

## 表示と操作

４語を選び照合。１組100点、３組300点。３語一致なら「あと１枚」、４回の間違いで全解説。繰り返した組み合わせで回数は減らさない。最後の組も４語を選んで送る。途中の答え公開は発見済みの点数を維持する。

正解パネルには、難易度・カテゴリ・４語・短い意味と対応表をそのまま表示。「背景を読む」は補足のみ。16枚版のように長文の折り畳みを開かないと関係が伝わらない状態を避ける。先に見つけた長い説明で残りの盤面を押し下げないよう、残りの単語を上に置く。

280／320／390pxの狭い画面と720／1280pxの広い画面でも４列を保つ。幅の変更では状態を初期化しない。実際の折りたたみ端末やヒンジのハードウェアを試験したのではなく、Chromiumのビューポート変更で確認する。ヒンジをまたぐ特別な二画面モードは導入しない。

## 保存・共有・実装

`server/connections.js` で判定・得点・正解開示を扱う。写真版とデータ版を分け、写真版の正解済み記録を単語版の正解として引き継がない。保存は既存の匿名CookieとJSON。再送の重複処理防止、レスポンス喪失後の復元、やり直し後に遅れて届いた古いゲームの送信拒否を維持する。

コピーとPNGは点数、発見した組数、結果の色履歴、URLのみ。出題語や答えのカテゴリ名は含めない。画像・地図・外部AI APIを新画面から呼ばない。16枚版の生成原本・WebP・原稿は制作履歴として残すが、新画面には使わない。

## 検証

- Node：初期の正解非公開、12語と３組、所属の重なりと完全分割、不正入力、近い回答、再送、全正解／全不正解、途中公開と古いゲームの送信。
- Chromium：４列表示、280／320／390／720／1280pxではみ出さない、選択中の幅変更で選択が残る、紫の対応表を開封操作なしで読める、保存済み回答のレスポンス喪失からの復元、再読み込み、結果コピー・PNG・やり直し。クリップボードのみテスト用に置換する。
