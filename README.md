# 土着信仰調査室・地理クイズ（試作版）

**現在は、12枚の写真を４枚ずつ３組に分ける試作です。** [デモを開く](https://fieldnotes-atlas-preview.onrender.com/?mode=connections&v=15)。仮称「異聞調査録」、固定１問「残された十二枚」。初級・中級・最難関の３組、最大300点、４回の間違いで答え合わせ。櫛が二つのカテゴリに入る見かけの重なりを保ち、写真で選べるようにしました。

[現在の仕様・原稿・正解・画像](docs/PHOTO_CONNECTIONS_DEMO.md)。盤面は文字カードではなく、iPhoneスナップ風の生成写真。供物の配置、糸で縛った物、残された髪や蝋など、私的な儀式に使われたような状態を創作で演出しています。正解すると写真が集まり、線・写真の変化・人型との対応で関係を見せます。拡大時に物の名前を確認でき、詳しい背景・典拠は追加で読めます。狭い／広い画面、並べ替え、途中保存、答えを含まない結果コピー・PNG保存に対応。一枚約390KiBのローカル写真素材を使い、外部地図・AI APIは呼びません。典拠は『古事記』上巻。写真の加工や配置は実在儀礼の再現とは扱わず、オンラインの参照先本文も今回未照合と表示します。

制作方針は [PROJECT_BRIEF.md](PROJECT_BRIEF.md) の先頭を参照。匿名セッションの試作用JSON保存で、再デプロイ等で記録を失う可能性があります。毎日の新問や課金は未導入です。旧 [12単語版の仕様](docs/WORD_CONNECTIONS_DEMO.md) と、旧16枚版の [仕様・画像の記録](docs/IMAGE_CONNECTIONS_DEMO.md) は履歴として保持します。

以前の [３枚の写真と一問のデモ](https://fieldnotes-atlas-preview.onrender.com/?mode=fieldwork&v=11) は維持しています。[当時の仕様](docs/VISUAL_INVESTIGATION.md)。

以前の「考察→土地の発見→調査録」の [３話デモ](https://fieldnotes-atlas-preview.onrender.com/?mode=casebook) も保持しています。手がかりを開き、候補語をタップして短い報告書の２カ所を埋め、答えと背景を読んでから地域を知ります。不正解でも３話すべての記録が地図に残ります。固定３話・日本語・各100点です。

[以前の３話の仕様と検証](docs/DEDUCTION_DEMO.md) ／ [正解を含む３話の原稿](docs/DEDUCTION_MANUSCRIPTS.md)。外部地図タイル・WebGLを使わず、開封演出・再現イラスト・調査済み地域の地図を表示します。

## 起動

Node.js 20.19 以上を用意し、リポジトリ直下で実行します。

```sh
npm ci --cache /tmp/fieldnotes-npm-cache
npm run dev
```

`http://localhost:3000/` で遊べます。サーバー側の回答記録は `.data/sessions.json` に保存されます。別ポートにする場合は `PORT=3001 npm run dev` を使います。

本番相当のビルドと起動は次のとおりです。

```sh
npm run build
npm run start
```

`npm test` は日付・採点と、5問回答、二重送信、ヒント利用、保存の API を確認します。

全5問を終えると、点数・日付・ヒント使用状況を載せた結果画像を共有またはPNG保存できます。正解地点は載りません。画像共有に対応するスマホではOSの共有画面から投稿先を選べます。未対応ブラウザでは画像保存と投稿文コピーを使います。

`npm run test:browser` は、まず新デモの開封・穴埋め・部分点・通信失敗時の保存照合・段階的な地域公開・全問の地図記録・共有を確認します。続いて旧地図デモを実ブラウザ（Chromium）でモバイルのピンチ拡大、ドラッグ、仮置き・3回の照合・距離による資料開封、canvasとズームの維持、線の伸長と到着、スキップ・再生、各巻の保存、動きを減らす設定、得点画像の共有をテストします。OS の Chromium がなければ `npx playwright install chromium` で入れるか、`CHROMIUM_PATH` を設定します。このテストの地図データは固定の代替データです。外部の地図配信が実際に機能するかは別途確認が必要です。

スマホから開ける確認用 URL の作成手順は [DEPLOY.md](DEPLOY.md) にあります。Render の無料サービス向け設定を同梱しています。URL は実際にデプロイしてから発行されます。

## 試作上の注意

- 問題データは `content/questions.json` にあり、公開 UI の初期 API レスポンスに正解座標や解説は含めません。回答はサーバーで採点し、確定後に正解を返します。
- 固定の10問を巻一・巻二に分け、日付によって最初に開く巻を交互にします。右上メニュー内で両方を選べます。日々の新問供給はまだありません。巻と日付ごとに回答を保存し、切替でもやり直しにはなりません。
- 無料・有料の切替は体験確認用です。誰でも切り替えられ、課金機能はありません。公開ランキングもありません。
- 広告枠は配置確認用で、AdSense のコードや同意管理は未接続です。
- 問題は `needs_review` です。公式資料の URL と対象施設の座標、日英の表現を人が照合し、確認日・確認者を記録してから公開してください。広域遺産の UNESCO ページだけで個別施設の位置を確定しないでください。
- 匿名の端末ごとに Cookie で進行を保存します。`.data` の JSON ファイルは単一 Node.js プロセスでの試作用です。公開版では利用者認証、永続 DB、サーバーで検証する課金状態を導入してください。

通常画面はMapLibreの平面地図で、最大ズーム19。Esri World Imageryの航空写真を基本に、OpenFreeMapの道路地図へ切り替えられます。ブラウザから `https://tiles.openfreemap.org` と `https://server.arcgisonline.com` への通信が必要です。現場資料は実際の航空写真から生成したJPEGとOSM由来のSVGで、各問の資料のみ読み込みます。帰属表示を維持してください。初回と新しい地域の地図取得には通信時間がかかります。

GeoSports の公開ルールとブラウザ用地図スタイル、ユーザー提供の実画面写真から確認した範囲は [docs/REFERENCE_REVIEW.md](docs/REFERENCE_REVIEW.md) に記録しています。通常のブラウザ自動試験は代替タイルを使用します。旧球体版では別途、実際の衛星画像とベクトル地図を証明書検証付き通信で取得して描画を確認しました。クラウドのブラウザ固有のCA信頼問題と、実機の通信・配信条件は区別しています。
