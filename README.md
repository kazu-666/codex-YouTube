# 土着信仰調査室・地理クイズ（試作版）

実在の史跡や信仰に関わる場所を世界地図で当てる、スマートフォン向けの5問クイズです。企画と暫定仕様は [PROJECT_BRIEF.md](PROJECT_BRIEF.md) に記録しています。

題材を先に見極めるため、[世界の信仰・伝承と実在地点の予備目録](docs/WORLD_STORY_SURVEY.md) と [候補CSV](research/world-story-candidates.csv) を用意しています。37カ国・60地点は本文未照合の調査候補で、公開可能と確認した問題数ではありません。

[無料公開時の運営費調査](docs/OPERATING_COSTS.md) にはGeoSports公式の利用サービス説明と人数別の試算を記録しています。公式料金表への接続は未完了で、金額は確定見積もりではありません。

## 起動

Node.js 20.19 以上を用意し、リポジトリ直下で実行します。

```sh
npm ci --cache /tmp/fieldnotes-npm-cache
npm run dev
```

`http://localhost:3000/` で遊べます。サーバー側の回答記録は `.data/sessions.json` に保存されます。別ポートにする場合は `PORT=3001 npm run dev` を使います。

本番相当のビルドと起動は次のとおりです。

```sh
npm run build
npm run start
```

`npm test` は日付・採点と、5問回答、二重送信、ヒント利用、保存の API を確認します。

全5問を終えると、点数・日付・ヒント使用状況を載せた結果画像を共有またはPNG保存できます。正解地点は載りません。画像共有に対応するスマホではOSの共有画面から投稿先を選べます。未対応ブラウザでは画像保存と投稿文コピーを使います。

`npm run test:browser` は実ブラウザ（Chromium）でモバイルのピンチ拡大、ドラッグ、タップ回答、ピンの大きさ、詳細表示時の中心位置をテストします。OS の Chromium がなければ `npx playwright install chromium` で入れるか、`CHROMIUM_PATH` を設定します。このテストの地図データは固定の代替データです。外部の地図配信が実際に機能するかは別途確認が必要です。

スマホから開ける確認用 URL の作成手順は [DEPLOY.md](DEPLOY.md) にあります。Render の無料サービス向け設定を同梱しています。URL は実際にデプロイしてから発行されます。

## 試作上の注意

- 問題データは `content/questions.json` にあり、公開 UI の初期 API レスポンスに正解座標や解説は含めません。回答はサーバーで採点し、確定後に正解を返します。
- 現在の5問は毎日順番だけ変えて出します。正式公開前に日別の問題を増やしてください。
- 無料・有料の切替は体験確認用です。誰でも切り替えられ、課金機能はありません。公開ランキングもありません。
- 広告枠は配置確認用で、AdSense のコードや同意管理は未接続です。
- 問題は `needs_review` です。公式資料の URL と対象施設の座標、日英の表現を人が照合し、確認日・確認者を記録してから公開してください。広域遺産の UNESCO ページだけで個別施設の位置を確定しないでください。
- 匿名の端末ごとに Cookie で進行を保存します。`.data` の JSON ファイルは単一 Node.js プロセスでの試作用です。公開版では利用者認証、永続 DB、サーバーで検証する課金状態を導入してください。

地図は MapLibre の地球儀表示、Esri World Imagery の衛星写真、OpenFreeMap のベクトル地図を使います。1本指のドラッグで回し、2本指のピンチで拡大できます。最大ズームは19で、島・道路・建物・施設名まで読む設計です。地図を1回タップすると回答が確定します。衛星写真が読めない場合はベクトル地図で続けられます。ブラウザから `https://server.arcgisonline.com` と `https://tiles.openfreemap.org` に接続するため通信が必要です。地図上の配信元と OpenStreetMap 等のクレジットを保持してください。広告・課金を伴う正式公開前に、画像配信の利用条件と実機での画像解像度を確認してください。

GeoSports の公開ルールとブラウザ用地図スタイル、ユーザー提供の実画面写真から確認した範囲は [docs/REFERENCE_REVIEW.md](docs/REFERENCE_REVIEW.md) に記録しています。実際の衛星画像配信はこのクラウドからアクセスできず、ブラウザテストでは代替タイルを使用します。
