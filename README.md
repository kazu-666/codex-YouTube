# 土着信仰調査室・地理クイズ（試作版）

日本の怪異・寺社の伝説・神話にゆかりのある実在地点を地図で当てる、スマートフォン向けの探索クイズ体験版です。巻一・巻二の各5問、合計10問を遊べます。企画と暫定仕様は [PROJECT_BRIEF.md](PROJECT_BRIEF.md) に記録しています。

[日本10問の編集資料・確認状況](docs/JAPAN_DEMO_QUESTIONS.md) に、ヒント・解説・採点地点・出典と実装範囲をまとめています。[日本版の小さな地球](docs/JAPAN_GLOBE.md) には、日本列島が球体の大部分を占める表示と詳細地図への切替、2行の問題文と簡潔な結果画面の設計を記録しています。地図上にピンを仮置きしてボタンで確定すると、正解へ線が伸び、距離・得点・短い解説が地図の下に現れます。スキップ・再生・動きを減らす設定に対応しています。

本格開発前のコンセプト検証も継続します。[コンセプト整理案と試遊計画](docs/CONCEPT_REVIEW.md) に、確認済みの初期対象者（今のSNS・YouTubeの視聴者）、日本先行の提案、完成5問で試す順番、現行採点の問題点をまとめています。日本10問を今回の体験版に採用し、長期の出題範囲は未確定です。

題材を先に見極めるため、[世界の信仰・伝承と実在地点の予備目録](docs/WORLD_STORY_SURVEY.md) と [候補CSV](research/world-story-candidates.csv) を用意しています。37カ国・60地点は本文未照合の調査候補で、公開可能と確認した問題数ではありません。

[無料公開時の運営費調査](docs/OPERATING_COSTS.md) にはGeoSports公式の利用サービス説明と人数別の試算を記録しています。公式料金表への接続は未完了で、金額は確定見積もりではありません。

## 起動

Node.js 20.19 以上を用意し、リポジトリ直下で実行します。

```sh
npm ci --cache /tmp/fieldnotes-npm-cache
npm run dev
```

`http://localhost:3000/` で遊べます。サーバー側の回答記録は `.data/sessions.json` に保存されます。別ポートにする場合は `PORT=3001 npm run dev` を使います。

本番相当のビルドと起動は次のとおりです。

```sh
npm run build
npm run start
```

`npm test` は日付・採点と、5問回答、二重送信、ヒント利用、保存の API を確認します。

全5問を終えると、点数・日付・ヒント使用状況を載せた結果画像を共有またはPNG保存できます。正解地点は載りません。画像共有に対応するスマホではOSの共有画面から投稿先を選べます。未対応ブラウザでは画像保存と投稿文コピーを使います。

`npm run test:browser` は実ブラウザ（Chromium）でモバイルのピンチ拡大、ドラッグ、仮置きと確定、線の伸長と到着、スキップ・再生、全10問と各巻の保存、動きを減らす設定、得点画像の共有をテストします。OS の Chromium がなければ `npx playwright install chromium` で入れるか、`CHROMIUM_PATH` を設定します。このテストの地図データは固定の代替データです。外部の地図配信が実際に機能するかは別途確認が必要です。

スマホから開ける確認用 URL の作成手順は [DEPLOY.md](DEPLOY.md) にあります。Render の無料サービス向け設定を同梱しています。URL は実際にデプロイしてから発行されます。

## 試作上の注意

- 問題データは `content/questions.json` にあり、公開 UI の初期 API レスポンスに正解座標や解説は含めません。回答はサーバーで採点し、確定後に正解を返します。
- 固定の10問を巻一・巻二に分け、日付によって最初に開く巻を交互にします。右上メニュー内で両方を選べます。日々の新問供給はまだありません。巻と日付ごとに回答を保存し、切替でもやり直しにはなりません。
- 無料・有料の切替は体験確認用です。誰でも切り替えられ、課金機能はありません。公開ランキングもありません。
- 広告枠は配置確認用で、AdSense のコードや同意管理は未接続です。
- 問題は `needs_review` です。公式資料の URL と対象施設の座標、日英の表現を人が照合し、確認日・確認者を記録してから公開してください。広域遺産の UNESCO ページだけで個別施設の位置を確定しないでください。
- 匿名の端末ごとに Cookie で進行を保存します。`.data` の JSON ファイルは単一 Node.js プロセスでの試作用です。公開版では利用者認証、永続 DB、サーバーで検証する課金状態を導入してください。

全体表示はThree.jsによる「日本列島が東西方向に球体の約288度を使う球体」で、1本指で回し、ピンチで拡大できます。十分近づくと、実座標のMapLibre + OpenFreeMap地図へ切り替わり、最大ズーム19で道路・建物・施設名を探せます。縮小や全体表示ボタンで日本の球体へ戻ります。回答前後で地図の高さ・球体のカメラ距離を維持し、詳細表示も保持します。先端の光と残光を伴う弧が加減速して正解へ進みます。球体の表示倍率は採点に使わず、クリックを実座標へ逆変換してサーバーで距離を求めます。

衛星写真はEsri World Imagery、日本の輪郭はNatural Earth由来のworld-atlasデータ。衛星写真が取得できなくても輪郭で球体を操作できます。ブラウザから `https://server.arcgisonline.com` と `https://tiles.openfreemap.org` への通信が必要です。Esri・Natural Earth・OpenStreetMap等の帰属表示と同梱ライセンスを維持してください。正式公開向けの配信条件・利用契約とスマホ実機での確認は残っています。

GeoSports の公開ルールとブラウザ用地図スタイル、ユーザー提供の実画面写真から確認した範囲は [docs/REFERENCE_REVIEW.md](docs/REFERENCE_REVIEW.md) に記録しています。通常のブラウザ自動試験は代替タイルを使用します。日本10問版では別途、実際の衛星画像とベクトル地図を証明書検証付き通信で取得して描画を確認しました。クラウドのブラウザ固有のCA信頼問題と、実機の通信・配信条件は区別しています。
